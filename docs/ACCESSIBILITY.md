# Accessibility

Target: WCAG 2.2 AA.

- Semantic `nav`/`main`/`aside` landmarks
- Visible `:focus-visible` rings
- Attention categories are words, not color names
- `prefers-reduced-motion` disables animation
- Form controls have labels

Automated UI axe scans are not claimed PASS until a browser runner is added. Backend attention-label tests exist.
